# 瓶詰め・入荷記録ツール

パートスタッフ向けの、瓶詰め・入荷入力と在庫管理のツールです。

## 運用画面

- 入力画面: 瓶詰めと入荷を切り替えて入力
- 編集者画面: `/admin`（Vol.、プログラム名、ワイン名、インポーター名、小瓶換算を編集）
- 管理スプレッドシート: 商品マスタ・在庫／瓶詰め記録／入荷記録の3タブ

## できること

- `vol.1-1` から `vol.12-4` の48銘柄をワイン名付きで表示
- 瓶詰め: 使用本数と `本数 × 7.5` の小瓶数を自動計算
- 瓶詰め本数が0でも、備考が入力されていれば備考のみの記録として送信
- 両方の記録で、作業日・記入者名・直近2日間の履歴を表示
- 入荷: Vol.ごとのプログラム・ワイン名・インポーター名・入荷本数・仕入先・備考を記録
- 入力内容を管理スプレッドシートへ追記し、Slack `#瓶詰め` に通知
- 商品マスタ・在庫では「基準在庫 + 入荷累計 − 瓶詰め使用」で現在庫を自動計算
- 編集者画面で追加した未登録プログラムは、最初の送信時に商品マスタへ自動追加（基準在庫0本）

## 連携設定

Vercelには次の環境変数が必要です。値は公開・ソースコードに含めません。

- `SLACK_WEBHOOK_URL`: `#瓶詰め` 向けIncoming Webhook
- `GOOGLE_APPS_SCRIPT_URL`: 管理シート追記用のApps Script Web App URL
- `GOOGLE_SHEETS_SYNC_SECRET`: Apps Scriptとの共有シークレット
- `BLOB_READ_WRITE_TOKEN`: 編集者設定の保存先
- `ADMIN_SECRET`: 編集者画面のパスワード

## 注意

入力内容は先にスプレッドシートへ記録され、その後Slackへ通知します。Slack送信だけに失敗した場合、画面は「スプレッドシートには記録済み」と表示するため、同じ内容を再送しないでください。

## Apps Script

共有用ソースは `apps-script/Code.gs` にあります。管理スプレッドシートで「拡張機能 → Apps Script」を開き、次の手順で設定します。

1. `Code.gs` の内容をApps Scriptへ反映します。
2. プロジェクトのタイムゾーンを `Asia/Tokyo` にします。
3. スクリプトプロパティ `SYNC_SECRET` に十分に長い共有シークレットを保存します。
4. スプレッドシートに紐づかない単独プロジェクトで使う場合だけ、`SPREADSHEET_ID` も保存します。
5. Webアプリとして「自分として実行」「アクセスできるユーザー: 全員」でデプロイします。
6. WebアプリURLをVercelの `GOOGLE_APPS_SCRIPT_URL`、同じ共有シークレットを `GOOGLE_SHEETS_SYNC_SECRET` に設定します。

実際のWebアプリURL、共有シークレット、Slack Webhook、管理画面パスワードはGitHubへ保存しないでください。
